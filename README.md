# Beacon

自托管 Android 消息推送应用，提供 Go/SQLite 与 Cloudflare Workers 两种服务端。

完整使用、部署、设计和验证资料统一维护在独立的 [文档仓库](https://github.com/ZeroHomers0/beacon-docs)（私有）；本地目录为 `docs-repo/`，使用入口为 `docs/Beacon-使用与部署指南.md`。

安装包见 [Releases](https://github.com/ZeroHomers0/beacon/releases)。源码目录：`android/`、`server/`、`workers/`。
