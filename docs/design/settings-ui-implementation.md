# Beacon 二级页面 UI 实施与验收记录

日期：2026-10-24。改动在 main 完成，提交记录见 Git 历史。

## 已实施

- 保留现有图标、页面框架和 MIUIX / Material 3 切换。共用组件统一信息顺序、圆角、内边距和文字行高；不引入玻璃效果或额外装饰。
- 连接状态、运行状态、服务器概况复用同一状态摘要和信息卡。正常底色减淡，对钩只叠放绘制，不参与测量；文字与标记保持间距。修正大字体下非线性字号换算导致的高度变化。
- 长值先缩字、再省略，逻辑行高不随缩字改变。长地址、版本、清理记录等可打开统一弹窗查看与选择复制完整原文；普通信息没有虚假的跳转反馈。
- 文字按钮共用同一种外观和交互。危险动作保留红色文字与确认。导航、复制、导入导出等入口采用对应菜单行；菜单项不再被文字按钮底色包裹。
- 设置行标题与摘要保持单行；选择项不再因所选值长度而在横排与竖排之间切换。开关由整行统一处理，避免开关和行重复回调。
- 设备/应用列表的名称、标识、状态固定排列；移除按字符数硬截断和状态栏自动换行，完整 ID 与所属设备信息进入详情弹窗。筛选与清除入口保留位置。
- 设置备份与消息备份各自成组，导入导出改为菜单行，结果进入弹窗。关闭反馈不改变操作卡片高度。
- 自动清理先展示上次确认的配置快照，进入页面后再刷新；清理记录保持同一结构。统计卡片列数只随窗口和字体变化，不随数值变化。
- 后台权限保持紧凑菜单行，去掉重复分组标题和说明入口。通知权限改为一个状态/授权入口，移除重复授权按钮和频道内的重复权限说明。
- 接收规则与免打扰的从属选项保留位置，关闭主开关时禁用；工作日选择区不自动插入。继承配置改为统一弹窗编辑。
- 使用向导保持四个步骤、测试结果、通知确认与完成按钮的位置；只有实际接收确认才能完成，失败与迟到结果不作为完成依据。
- 断线和保存失败通过统一反馈处理，不再在列表顶部插入卡片。普通瞬时绑定等待经过短暂延迟后才提示，避免启动闪窗。
- 统一弹窗标题、正文滚动、底部等宽按钮；移除 Material 时间选择器和模式弹窗中的嵌套无限高度滚动，修复交互崩溃。
- 当天时间只显示 HH:mm:ss，其他日期保留 yyyy-MM-dd HH:mm:ss；自动清理记录使用同一规则。
- 每个刷新入口只为自己的点击显示动画，后台忙碌不再带动其他刷新按钮；连接状态标记不旋转。开发者工具保留密钥菜单，示例弹窗直接展示四种复制选项。
- 关于页收紧 Logo、名称与版本排布，链接仍为统一菜单；更新日志由共用弹窗滚动。

## 验收边界

截图使用固定样本数据，不含真实凭证或消息。管理截图验证实际共用组件与详情菜单，没有连接用户的真实服务器。模拟器已验证两套主题与大字体；真实手机厂商字体、输入法、系统权限页及实际服务器操作仍需安装体验。截图中的测试页标题用于标识路由，实际应用继续使用现有导航框架。

## 后续调整：状态卡排序与统计卡片

- 连接状态、运行状态、服务器概况位于各自页面内容顶部。
- 接收模式在运行状态下方平铺即时、省电、规则三个选项，保留未保存修改的确认保护。
- 消息列表左上角模式入口保留选择弹窗，只有设置中的接收模式页面平铺三种模式。
- 数据库存储、消息数量、清理预览与服务器统计统一使用独立卡片、相同圆角、底色、间距及数字排版；取消统计外层的嵌套大卡片。
- 新增接收页状态优先顺序和三种模式直接选择的双主题设备回归。

本次调整验证：Debug 构建通过，329 项单元测试通过，18 项设备回归通过（0 失败）。MIUIX 保存测试等待实际请求回调后再验证禁用状态，消除点击回调时序引起的不稳定。结果保存于 android/app/build/ui-qa/layout-update-18/。

## 后续调整：按钮尺寸规则与模式分隔

- 三种接收模式取消分割线。图标、两行文字、统一留白与选中对钩足以区分选项，保持完整行点击区域。
- 卡片内单个文字按钮占满内容宽度；同组多个文字按钮等宽，空间不足时上下排列，堆叠后也等宽等高。
- 弹窗底部与卡片动作复用同一布局；单个满宽，双按钮等宽。按钮不恢复主次样式，危险动作仅用红字区分。
- 刷新、复制、更多等工具入口保留统一图标尺寸。服务器退出入口改为带无障碍标签的图标，避免标题被文字按钮挤压；密钥示例复制图标不参与文字按钮的等宽计算。
- 补充单按钮满宽、不同文案等宽、禁用尺寸不变，以及大字体下等宽堆叠的双主题设备测试。

最终提交验证：Debug 构建通过，329 项 JVM 单元测试和 56 项设备回归全部通过，0 失败、0 跳过；Lint 为 0 错误、125 条警告、1 条提示。最终设备报告位于 android/app/build/ui-qa/final-submit-56/，截图位于 android/app/build/ui-qa/final-submit-screenshots/。初次启动模拟器时的安装就绪时序失败，在确认系统启动完成后完整重跑通过。

## 实际页面外壳与列表一致性复查

- 定位并修正 MIUIX Scaffold 默认 surface 为白色的问题：实际页面容器明确使用 background，与白卡片区分；标题栏使用相同页面底色。
- 所有设置路由使用可滚动折叠的大标题，不再强制二级页使用小标题；切换路由重建对应标题滚动状态。
- 消息多选改为右侧 32dp 槽位，替换更多图标；不占用左侧文字宽度，卡片边界和标题位置保持不变。
- 正常状态卡增强绿色底色与圆圈对钩，圆圈和对钩均加粗，仍使用叠放绘制而不参与测量。
- 待通知读取增加专属 loading 状态；点击刷新时出现动画，无关后台操作不触发动画。
- 设备/应用管理搜索与数量固定在列表上方，复用消息搜索框和数量胶囊；状态及所属设备筛选进入右上角图标菜单，已选条件通过可移除标签展示，取消清除筛选按钮和旧文本统计。
- 接收模式、选择器及开关文案的禁用反馈统一；精简规则说明；三个统计项在大字体无法三列展示时整列排列，避免 2+1 留白；占用卡片文案改为已用空间。
- 连接编辑、自定义清理、解绑与备份导入的状态采用固定位置，移除子弹窗中重复的滚动层，减少错误反馈造成的尺寸变化。
- 左上角模式入口恢复选择弹窗；设置页保留平铺，两个入口共用同一切换与未保存修改确认逻辑。
- 此前截图只包裹内容面板，未覆盖真实 Scaffold 默认底色和标题行为；本轮改用实际页面外壳生成截图，补充背景像素区分、标题展开与滚动折叠、多选边界、筛选标签及通知刷新动画回归。

- 免打扰星期选择补充选中底色与对钩；普通操作按钮仍不分主次。选中标记始终预留同宽槽位，防止状态变化造成换行。直接点击星期会自动进入自定义，预设与星期状态相互对应，保存时使用相同星期位掩码。

本轮实际页面修正验收：构建及 329 项单元测试通过；66 项主设备回归通过，追加星期选择后的 20 项最终复核通过，均为 0 失败。最后 Lint 为 0 错误、125 条警告、1 条提示。报告分别保存在 android/app/build/ui-qa/shell-consistency-66/ 与 android/app/build/ui-qa/consistency-final-20/；128 张最终截图位于 android/app/build/ui-qa/consistency-final-screenshots/。星期用例覆盖两套主题和普通/2 倍字体，检查选中颜色、对钩、点击后边界不变及实际表单星期位掩码。
