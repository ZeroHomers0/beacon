# UI 全局防复发检查

日期：2026-10-24。范围：消息列表、详情、全部设置路由、服务器管理列表、共用弹窗、工具动作与标签。保留现有图标及 MIUIX / Material 3；普通操作按钮仍不分主次。

| 问题类型 | 全局检查与处理 |
| --- | --- |
| 白卡片与背景融为一体 | 两套 Scaffold、消息搜索区、消息/设置切页容器统一使用页面 background；普通卡片使用卡片 surface，状态卡使用单独状态底色。修复切页容器用 surface 覆盖 Scaffold 背景的问题，回归实际页面与完整嵌套切页链路。 |
| 二级标题提前收起 | 设置路由统一使用可折叠大标题；消息详情、多选等有明确用途的小标题保留。上次加入的实际 Scaffold 展开/折叠回归继续执行。 |
| 多选控件撑开卡片 | 消息选择控件复用右侧更多槽位；本轮进一步检查待通知状态，改用固定通知图标槽，不再额外增加一行。应用、分组标签位置不随待通知和选择状态变化。 |
| 选择后没有反馈 | 星期选项保留选中底色和对钩，统计筛选具备选中语义；下拉选项始终保留同宽对钩槽，长标签单行显示。 |
| 按钮突然由横排变竖排 | 共用动作组只按窗口和字号决定排列，不再按可能变化的操作文案决定；按钮标签固定单行。多阶段确认和长失败反馈不会改变按钮边界。 |
| 多个刷新入口转动、快速请求无动画 | 图标刷新与接收页的同步按钮共用点击归属和最短可见反馈；未点击的控件不因后台 busy 联动。同步完成的请求也有短暂反馈，迟到的共享 busy 不会继承归属。 |
| 失败结果挤压原内容 | 管理确认对话框使用固定状态位置；提醒刷新失败优先显示失败信息，不被旧数量遮住。分享/打开操作失败使用共用失败弹窗；链接确认保留固定状态位置。 |
| 弹窗滚动样式不一致 | 应用弹窗入口均使用 BeaconAlertDialog，清理剩余 OperationResultPanel 子滚动，避免同一正文形成双层滚动。 |
| 筛选条风格分叉 | 消息、设备及应用列表共用同一个可移除筛选标签组件；继续复用搜索框、统计胶囊和右上角筛选菜单。 |
| 管理列表布局分叉 | 设备/应用三个点复用消息的 32dp 控件、20dp 图标及首行居中槽位；有效/撤销及通知级别复用消息标签并在右下角同排。移除空列表状态项、重复顶部内边距与应用列表重复文字统计。 |
| 深色标签偏暗或文字失去对比 | 元数据八色板改为不透明亮色，移除暗棕等深色；筛选和日期选项使用亮蓝色系。搜索下方两个数量统计遵照最终要求保留纯灰，选中只改变灰度。两套标签文字组件明确使用相同深色前景，修正 MIUIX 深色主题白字继承问题。 |
| 缺值加载后增加一行 | 信息行及下拉偏好行使用明确占位值；现有清理快照、字段逻辑行高和固定统计列数规则保留。 |

## 标签规则

- 保持应用/分组的既有稳定分桶算法，只替换展示色板，不引入用户数据或额外图标。
- 天蓝、薄荷、浅紫、琥珀、玫红、草绿、青色与珊瑚橙在深浅主题均保持明亮。
- 小字号标签采用统一深色文字；单元测试覆盖八色与选中颜色的亮度、不透明度和至少 7:1 的文字对比度。
- UI 回归从实际文字布局读取前景色，防止 Material 与 MIUIX 的 LocalContentColor 再次分叉；截图保留实际渲染结果。

## 状态卡参考取色

用户提供的正常状态卡截图含 Display P3 配置。按配置转换至标准 sRGB 后，大面积底色为 `#DFFAE4`，圆圈及对钩为 `#35D267`。三个正常状态卡均使用上述不透明颜色，明暗主题一致，并显式使用深色文字；异常状态保持原有语义色。图标轮廓、卡片布局及尺寸不变。

搜索下方数量统计使用纯灰：浅色主题选中 `#DDDDDD`、普通 `#EEEEEE`；深色主题选中 `#3C3C3C`、普通 `#292929`，与彩色元数据标签区分。

## 验证与边界

新增 CardSurfaceRegressionTest、GlobalUiStabilityTest、MessageFailureUiTest 和 BrightTagPaletteTest，覆盖实际消息/设置页的背景与卡片像素差异、管理标签位置、普通/2 倍字体、两套主题、深浅色、阶段文案变化、错误反馈、待通知/多选切换、快速响应与无关后台加载。

正文 Markdown、图片等内容按其实际内容加载；不把用户主动展开的正文/媒体锁成固定高度。测试使用模拟器与固定样本，不涉及真实服务器创建、删除和外链跳转。真机系统字体和系统权限页仍属于安装验收范围。

最终构建与 332 项单元测试通过；84 项完整 UI 回归全部通过。最后按用户要求调整状态卡取色及纯灰统计后，追加 20 项相关 UI 复核，全部通过；包括正常卡片底色/对钩实际渲染像素及统计底色纯灰断言。Lint 为 0 错误、125 条警告、1 条提示。
